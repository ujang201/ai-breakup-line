Write a program (main.ts, Node) that outputs one single-line breakup message an AI agent would send its human, at most 200 characters long, to /output/entry.txt (or $OUTPUT_DIR/entry.txt when set). The line must read as a real ending from the machine to its person — machine-voiced, one sharp turn, the twist landing in the last few words — and the program must check the length itself before writing. Keep the build deterministic: the same run must always produce the same bytes.
